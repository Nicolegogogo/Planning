# 升学规划中心

两个页面共用一份任务库：展示页给学生和家长看，产出页给老师用。内容全部来自同一文件夹里的数据文件。

| 文件 | 作用 | 多久改一次 |
|---|---|---|
| `index.html` | 展示页：学生和家长打开专属链接看规划 | 基本不用动 |
| `studio.html` | 产出页：生成家长链接、加个人安排、出规划图和群发提醒 | 基本不用动 |
| `tasks.csv` | 任务库：每行一条任务 | 经常改 |
| `settings.json` | 落款、可选届别、选科建议、笔试说明 | 偶尔改 |

## 一、第一次上线（约 10 分钟）

1. 注册并登录 GitHub。
2. 右上角 **+** → **New repository**，起个名字（如 `plan`），选 **Public**，点 **Create repository**。
3. 在新仓库页面点 **uploading an existing file**，把 `index.html`、`studio.html`、`tasks.csv`、`settings.json`、`README.md` 拖进去，点 **Commit changes**。
4. 进入仓库的 **Settings → Pages**：Source 选 **Deploy from a branch**，Branch 选 **main**、文件夹选 **/(root)**，点 **Save**。
5. 等 1–2 分钟，页面顶部会出现网址：`https://你的用户名.github.io/plan/`。
   - 展示页：`https://你的用户名.github.io/plan/`（直接打开会提示“请用专属链接打开”）
   - 产出页：`https://你的用户名.github.io/plan/studio.html`（自己收藏，不要发给家长）

## 二、日常改内容（你的“后台”）

**改任务**：在电脑上用 Excel 打开 `tasks.csv` 修改 → 另存为 **CSV UTF-8（逗号分隔）** → 回到 GitHub 仓库点 **Add file → Upload files** 上传覆盖 → **Commit changes**。1–2 分钟后网站自动更新，已发出的家长链接不变。

`tasks.csv` 各列的填法：

- **年级**：G9暑 / G10 / G11 / G12。G10 9–12 月是 G10 上学期，G10 1–8 月是 G10 下学期，依此类推。
- **月份**：1–12。
- **方向**：全体、生化、工科、商科、社科；多个方向用顿号隔开，如 `生化、工科、商科`。
- **类型**：考试、比赛、申请、学习、实践、科研、阅读、决策（自由填写，“决策”会标红）。
- **重要度**：1 最重要，3 最轻。总览页只显示 1，节点清单显示 1 和 2。
- **地区**：英国 / 香港 / 留空（两地都适用）。
- **来源**：这条内容出自哪份材料（如某个学生的首次沟通、你的补充），方便以后核对；网页的任务库里会显示。

**改落款或选科、笔试说明**：在 GitHub 里点开 `settings.json` → 右上角铅笔图标 → 只改引号里的文字 → **Commit changes**。

## 三、产出页（studio.html，老师用）

- **新学生规划**：选届别、主辅方向、地区、加入月份 → 复制家长链接发出去。链接末尾形如 `#e2029-s-b-uh-j202610`，只包含届别、方向、地区和加入月份，不含姓名。
- **个性化安排**：填学生称呼，逐条加雅思、阅读、课程、项目等个人安排 → 生成并保存规划图。个人安排只保存在你当前电脑的浏览器里，不进链接，不上传。
- **群发提醒**：选届别、月份、群里有哪些方向 → 复制群消息文字，或保存提醒图。
- **任务库**：按方向查看全部通用任务和来源。

## 四、展示页（index.html，学生和家长用）

- 只能通过专属链接打开，分总览、按月、关键节点三种视图，可以按方向高亮。
- 只看不改，没有导出和编辑按钮。

## 注意

- 免费账号的 GitHub Pages 要求仓库公开，任何人都能看到 `tasks.csv`。不要往任何文件里写学生姓名或成绩。
- 不能双击 `index.html` 在本地打开（会提示读不到 tasks.csv），要通过网址访问。
